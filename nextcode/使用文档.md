# NextCode 使用文档

## 安装

### 后端

```bash
cd nextcode
pip install -e .
```

### Ink 前端（可选）

Ink 前端提供更丰富的终端 UI 体验（Markdown 渲染、权限对话框、命令补全）。

```bash
cd nextcode/frontend
npm install
npm run build
```

> 如果未安装 Ink 前端，使用 `nextcode --ink auto` 或 `nextcode --ink on` 时会自动回退到 Rich REPL。

## 快速开始

### 配置 API Key

方式一：环境变量
```bash
# DeepSeek 模型
export NEXTCODE_API_KEY=your-deepseek-api-key

# Claude 模型
export ANTHROPIC_API_KEY=your-anthropic-api-key
```

方式二：交互式配置
```bash
nextcode auth
```

方式三：配置文件 `.nextcode/.settings.json`
```json
{
  "api_key": "your-api-key",
  "model": "deepseek-reasoner",
  "context": {
    "max_tokens": 65536
  }
}
```

配置文件位置：
- 全局配置：`~/.nextcode/.settings.json`
- 项目配置：`.nextcode/.settings.json`

## 命令行选项

```bash
# 查看版本
nextcode --version
nextcode -v

# 非交互模式（从 stdin 读取）
echo "解释什么是 Python 装饰器" | nextcode --print

# 指定模型
nextcode --model deepseek-reasoner
nextcode --model claude-sonnet-4-20250514

# 指定工作目录
nextcode --cwd /path/to/project

# 选择 UI 模式
nextcode --ink off      # 使用 Rich REPL（默认）
nextcode --ink auto     # 优先 Ink，不可用则回退 Rich
nextcode --ink on       # 强制使用 Ink 前端

# 查看配置
nextcode config
```

## 交互式 REPL

### 启动交互模式

```bash
# Rich REPL 模式（默认）
nextcode

# Ink 前端模式
nextcode --ink auto
```

### 内置命令

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助信息和可用命令列表 |
| `/clear` | 清空对话历史 |
| `/compact` | 压缩对话历史（模型摘要 + 保留近期消息） |
| `/context` | 显示上下文窗口使用情况（模型、token 用量、阈值等） |
| `/thinking` | 切换 Thinking 内容显示（默认关闭） |
| `/model` | 显示当前使用的模型 |
| `/log` | 显示对话循环状态日志 |
| `/exit` `/quit` `/q` | 退出 REPL |

> 输入 `/` 后按 Tab 键可补全命令。输入错误命令时会提示相似命令。

### 上下文窗口监控

使用 `/context` 命令查看详细的上下文窗口信息：

```

### 上下文压缩

当对话历史增长到接近上下文窗口限制时，系统自动执行压缩：

| 压缩级别 | 触发时机 | 行为 |
|---------|---------|------|
| MICRO | token 用量接近阈值 | 清除旧工具结果，保留最近 3 条 |
| FULL | token 用量达到阈值 | 模型生成摘要 + 保留近期消息 |
| BLOCKING | token 用量超出上限 | 拒绝新查询，需手动 `/compact` |

也可以随时手动执行 `/compact` 触发 FULL 压缩。

### Thinking 展示

- 默认关闭，使用 `/thinking` 命令开启
- 开启后，流式阶段实时显示 thinking 内容

### 权限确认

当工具需要执行写操作时，会弹出确认提示：

**Rich REPL：**
```
  ⚙ Bash wants to execute:
    command: ls -la
  Allow? [y/n/a(ll)]:
```

**Ink 前端：**
显示交互式权限对话框，可选择 Allow / Deny / Always Allow。

| 输入 | 行为 |
|------|------|
| `y` / `yes` | 本次允许 |
| `a` / `all` | 本次会话允许该工具所有操作，并持久化到 `.nextcode/.settings.json` |
| `n` / 其他 | 拒绝执行 |

```

## 多模型支持

NextCode 支持多种模型，自动选择对应的 API 后端：

| 模型前缀 | 后端 | Base URL | API Key 来源 |
|----------|------|----------|-------------|
| `deepseek-*` | OpenAI 兼容 | `https://api.deepseek.com` | `NEXTCODE_API_KEY` → settings |
| `claude-*` | Anthropic 原生 | `https://api.anthropic.com` | `ANTHROPIC_API_KEY` → settings |
| 其他 | OpenAI 兼容 | `https://api.deepseek.com` | `NEXTCODE_API_KEY` → settings |

### 模型上下文窗口与输出限制

| 模型 | 上下文窗口 | 最大输出 |
|------|-----------|---------|
| Claude Opus 4 | 200K | 32K |
| Claude Sonnet 4 | 200K | 16K |
| Claude 3.5 Sonnet/Haiku | 200K | 8K |
| Claude 3 Opus | 200K | 4K |
| DeepSeek | 128K | 8K |
| MiniMax | 200K | 8K |
| 默认 | 128K | 8K |

settings 中配置的 `max_tokens` 会自动按模型族限制，不会超出上限。

## 配置系统

配置优先级（从低到高）：
1. 默认值
2. 全局配置文件 `~/.nextcode/.settings.json`
3. 项目配置文件 `.nextcode/.settings.json`
4. 环境变量

### 配置示例

```json
{
  "api_key": "sk-your-api-key",
  "model": "deepseek-reasoner",
  "context": {
    "max_tokens": 65536,
    "compact_threshold": 0.8,
    "auto_compact_buffer": 13000,
    "blocking_buffer": 3000,
    "circuit_breaker_max_failures": 3,
    "microcompact_keep_recent": 3
  },
  "permissions": {
    "allow": ["Read:*", "Glob:*", "Grep:*"],
    "deny": [],
    "ask": []
  }
}
```

### 环境变量

| 变量 | 说明 |
|------|------|
| `NEXTCODE_API_KEY` | DeepSeek 等 OpenAI 兼容模型的 API Key |
| `ANTHROPIC_API_KEY` | Claude 模型的 API Key |
| `ANTHROPIC_BASE_URL` | Anthropic API 地址（可选） |
| `NEXTCODE_BASE_URL` | OpenAI 兼容 API 地址（可选） |
| `NEXTCODE_MODEL` | 覆盖默认模型 |
| `NEXTCODE_INK` | 覆盖 Ink 模式（off/auto/on） |

## 可用工具

| 工具 | 说明 | 权限默认 |
|------|------|----------|
| `Read` | 读取文件内容 | 允许 |
| `Glob` | 按模式查找文件 | 允许 |
| `Grep` | 搜索文件内容 | 允许 |
| `Bash` | 执行 shell 命令 | 需确认 |
| `Edit` | 编辑文件（字符串替换） | 需确认 |
| `Write` | 写入文件 | 需确认 |

> 只读工具（Read、Glob、Grep）默认允许，无需确认。选择 `a(ll)` 后，该工具的通配符权限会持久化到 `.nextcode/.settings.json`，下次启动自动生效。

## 故障排除

### API Key 未配置
```
Error: No API key found. Set NEXTCODE_API_KEY or run 'nextcode auth'.
```
解决：运行 `nextcode auth` 或设置环境变量 `NEXTCODE_API_KEY` / `ANTHROPIC_API_KEY`。

### 模块未找到
```
ModuleNotFoundError: No module named 'next_code'
```
解决：在项目目录运行 `pip install -e .`

### Ink 前端不可用
```
Ink frontend not available, falling back to Rich REPL.
```
解决：在 `frontend/` 目录运行 `npm install && npm run build`。

### Anthropic 报 invalid argument
检查 `max_tokens` 配置，Claude 模型最大输出 8192，超出会自动限制。

### 上下文窗口满
```
Context window full. Use /compact to manually compress the conversation.
```
解决：输入 `/compact` 手动压缩，或 `/clear` 清空对话。
