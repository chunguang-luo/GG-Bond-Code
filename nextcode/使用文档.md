# NextCode 使用文档

> 最后更新：2025-05-29

## 安装

### 后端

```bash
cd nextcode
pip install -e .
```

### Ink 前端

Ink 前端提供终端 UI 体验（Markdown 渲染、权限对话框、命令补全）。

```bash
cd nextcode/frontend
npm install
npm run build
```

## 快速开始

### 配置 API Key

方式一：环境变量
```bash
# DeepSeek 模型
export NEXTCODE_API_KEY=your-deepseek-api-key

# Claude 模型
export ANTHROPIC_API_KEY=your-anthropic-api-key
```

方式二：交互式配置
```bash
nextcode auth
```

方式三：配置文件 `.nextcode/.settings.json`
```json
{
  "api_key": "your-api-key",
  "model": "deepseek-reasoner",
  "context": {
    "max_tokens": 65536
  }
}
```

配置文件位置：
- 全局配置：`~/.nextcode/.settings.json`
- 项目配置：`.nextcode/.settings.json`

## 命令行选项

```bash
# 查看版本
nextcode --version
nextcode -v

# 非交互模式（从 stdin 读取）
echo "解释什么是 Python 装饰器" | nextcode --print

# 指定模型
nextcode --model deepseek-reasoner
nextcode --model claude-sonnet-4-20250514

# 指定工作目录
nextcode --cwd /path/to/project

# 查看配置
nextcode config
```

## 交互式 REPL

### 启动交互模式

```bash
nextcode
```

### 内置命令

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助信息和可用命令列表 |
| `/clear` | 清空对话历史 |
| `/compact` | 压缩对话历史（模型摘要 + 保留近期消息） |
| `/context` | 显示上下文窗口使用情况（模型、token 用量、阈值等） |
| `/thinking` | 切换 Thinking 内容显示（默认关闭） |
| `/model` | 显示当前使用的模型 |
| `/log` | 显示对话循环状态日志 |
| `/exit` `/quit` `/q` | 退出 REPL |

> 输入 `/` 后按 Tab 键可补全命令。输入错误命令时会提示相似命令。

### 上下文窗口监控

使用 `/context` 命令查看详细的上下文窗口信息：

```

            0/200k tokens (0%)
⛁ ⛁ ⛁ ⛶ 
            Estimated usage by category
⛶ ⛶ ⛶ ⛶ ⛶  ⛁ System prompt: 5.8k tokens (2.9%)
            ⛁ System tools: 16.9k tokens (8.5%)
⛶ ⛶ ⛶ ⛶ ⛶  ⛁ Skills: 591 tokens (0.3%)
            ⛁ Messages: 29.8k tokens (14.9%)
⛶ ⛝ ⛝ ⛝ ⛝  ⛶ Free space: 113.9k (57.0%)
            ⛁ Autocompact buffer: 33k tokens (16.5%)
```

### 上下文压缩

当对话历史增长到接近上下文窗口限制时，系统自动执行压缩：

| 压缩级别 | 触发时机 | 行为 |
|---------|---------|------|
| MICRO | token 用量接近阈值 | 清除旧工具结果，保留最近 3 条 |
| FULL | token 用量达到阈值 | 模型生成摘要 + 保留近期消息 |
| BLOCKING | token 用量超出上限 | 拒绝新查询，需手动 `/compact` |

也可以随时手动执行 `/compact` 触发 FULL 压缩。

### Thinking 展示

- 默认关闭，使用 `/thinking` 命令开启
- 开启后，流式阶段实时显示 thinking 内容

### 权限确认

当工具需要执行写操作时，会弹出确认提示：

```
  ⚙ Bash wants to execute:
    command: ls -la
  Allow? [y/n/a(ll)]:
```

| 输入 | 行为 |
|------|------|
| `y` / `yes` | 本次允许 |
| `a` / `all` | 本次会话允许该工具所有操作，并持久化到 `.nextcode/.settings.json` |
| `n` / 其他 | 拒绝执行 |

## 多模型支持

NextCode 支持多种模型，自动选择对应的 API 后端：

| 模型前缀 | 后端 | Base URL | API Key 来源 |
|----------|------|----------|-------------|
| `deepseek-*` | OpenAI 兼容 | `https://api.deepseek.com` | `NEXTCODE_API_KEY` → settings |
| `claude-*` | Anthropic 原生 | `https://api.anthropic.com` | `ANTHROPIC_API_KEY` → settings |
| 其他 | OpenAI 兼容 | `https://api.deepseek.com` | `NEXTCODE_API_KEY` → settings |

### 模型上下文窗口与输出限制

| 模型 | 上下文窗口 | 最大输出 |
|------|-----------|---------|
| Claude Opus 4 | 200K | 32K |
| Claude Sonnet 4 | 200K | 16K |
| Claude 3.5 Sonnet/Haiku | 200K | 8K |
| Claude 3 Opus | 200K | 4K |
| DeepSeek | 128K | 8K |
| MiniMax | 200K | 8K |
| 默认 | 128K | 8K |

settings 中配置的 `max_tokens` 会自动按模型族限制，不会超出上限。

## 配置系统

配置优先级（从低到高）：
1. 默认值
2. 全局配置文件 `~/.nextcode/.settings.json`
3. 项目配置文件 `.nextcode/.settings.json`
4. 环境变量

### 配置示例

```json
{
  "api_key": "sk-your-api-key",
  "model": "deepseek-reasoner",
  "context": {
    "max_tokens": 65536,
    "compact_threshold": 0.8,
    "auto_compact_buffer": 13000,
    "blocking_buffer": 3000,
    "circuit_breaker_max_failures": 3,
    "microcompact_keep_recent": 3
  },
  "permissions": {
    "allow": ["Read:*", "Glob:*", "Grep:*"],
    "deny": [],
    "ask": []
  }
}
```

### 环境变量

| 变量 | 说明 |
|------|------|
| `NEXTCODE_API_KEY` | DeepSeek 等 OpenAI 兼容模型的 API Key |
| `ANTHROPIC_API_KEY` | Claude 模型的 API Key |
| `ANTHROPIC_BASE_URL` | Anthropic API 地址（可选） |
| `NEXTCODE_BASE_URL` | OpenAI 兼容 API 地址（可选） |
| `NEXTCODE_MODEL` | 覆盖默认模型 |

## 可用工具

| 工具 | 说明 | 权限默认 |
|------|------|----------|
| `Read` | 读取文件内容 | 允许 |
| `Glob` | 按模式查找文件 | 允许 |
| `Grep` | 搜索文件内容 | 允许 |
| `Bash` | 执行 shell 命令 | 需确认 |
| `Edit` | 编辑文件（字符串替换） | 需确认 |
| `Write` | 写入文件 | 需确认 |

> 只读工具（Read、Glob、Grep）默认允许，无需确认。选择 `a(ll)` 后，该工具的通配符权限会持久化到 `.nextcode/.settings.json`，下次启动自动生效。

## MCP 扩展

NextCode 支持 [Model Context Protocol](https://modelcontextprotocol.io/)，可连接外部工具服务器扩展能力。

### 添加 MCP 服务器

在项目根目录创建 `.mcp.json`：

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

添加后重启 NextCode，服务器会自动连接。工具以 `mcp__<server>__<tool>` 命名注册（如 `mcp__playwright__browser_navigate`）。

### 传输类型

| 类型 | 说明 | 配置方式 |
|------|------|---------|
| `stdio`（默认） | 本地子进程 | 指定 `command` + `args` |
| `http` | Streamable HTTP（推荐远程） | 指定 `url` + 可选 `headers` |
| `sse` | Server-Sent Events | 指定 `url` + 可选 `headers` |
| `ws` | WebSocket | 指定 `url` |
| `sdk` | 进程内 SDK | 内嵌式集成 |

### 配置示例

**本地工具（stdio）**：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/projects"]
    }
  }
}
```

**远程服务（HTTP）**：

```json
{
  "mcpServers": {
    "remote-api": {
      "type": "http",
      "url": "https://api.example.com/mcp",
      "headers": { "Authorization": "Bearer token" }
    }
  }
}
```

**带 OAuth 认证的远程服务**：

```json
{
  "mcpServers": {
    "oauth-service": {
      "type": "http",
      "url": "https://api.example.com/mcp",
      "oauth": {
        "resource_url_url": "https://api.example.com/.well-known/oauth-protected-resource"
      }
    }
  }
}
```

**带动态鉴权的远程服务**（如云厂商临时凭证）：

```json
{
  "mcpServers": {
    "cloud-api": {
      "type": "http",
      "url": "https://api.example.com/mcp",
      "headersHelper": "./scripts/get-auth-headers.sh"
    }
  }
}
```

`headersHelper` 脚本输出格式：每行 `Header-Name: value`，每次连接前自动执行。

### 配置来源与优先级

| 来源 | 配置文件 | 优先级 |
|------|---------|--------|
| 项目级 | `.mcp.json` | 低 |
| 用户级 | `~/.nextcode/.settings.json` | 中 |
| 本地 | `.nextcode/.settings.local.json` | 中高 |
| 动态 | `--mcp-config` CLI 参数 | 高 |
| 企业 | `managed-mcp.json`（独占模式） | 最高 |

高优先级来源的同名服务器会覆盖低优先级。企业独占模式下仅加载企业配置，忽略所有其他来源。

### 连接状态

启动时日志会输出 MCP 连接状态：

```
MCP: playwright — connected      # 连接成功
MCP: playwright — failed         # 连接失败
MCP: playwright — needs-auth     # 需要 OAuth 认证
```

连接断开时自动重连，指数退避：1s → 2s → 4s → 8s → 16s（最大 30s），最多 5 次尝试。

### 常见 MCP 服务器

| 服务器 | 安装命令 | 用途 |
|--------|---------|------|
| Playwright | `npx @playwright/mcp@latest` | 浏览器自动化 |
| Filesystem | `npx @modelcontextprotocol/server-filesystem` | 文件系统访问 |
| GitHub | `npx @modelcontextprotocol/server-github` | GitHub API |
| PostgreSQL | `npx @modelcontextprotocol/server-postgres` | 数据库查询 |

### 故障排除

**MCP 服务器未连接**：
- 检查 `.mcp.json` 格式是否正确
- 确认 `command` 或 `url` 可访问
- 查看启动日志中的错误信息

**OAuth 认证失败**：
- 确认 `resource_url_url` 可访问
- Token 存储在 `~/.nextcode/mcp-tokens/`，删除后可重新认证

## 故障排除

### API Key 未配置
```
Error: No API key found. Set NEXTCODE_API_KEY or run 'nextcode auth'.
```
解决：运行 `nextcode auth` 或设置环境变量 `NEXTCODE_API_KEY` / `ANTHROPIC_API_KEY`。

### 模块未找到
```
ModuleNotFoundError: No module named 'next_code'
```
解决：在项目目录运行 `pip install -e .`

### Ink 前端不可用
```
Error: Ink frontend unavailable: Ink frontend bundle not found
```
解决：在 `frontend/` 目录运行 `npm install && npm run build`。

### Anthropic 报 invalid argument
检查 `max_tokens` 配置，Claude 模型最大输出 8192，超出会自动限制。

### 上下文窗口满
```
Context window full. Use /compact to manually compress the conversation.
```
解决：输入 `/compact` 手动压缩，或 `/clear` 清空对话。
