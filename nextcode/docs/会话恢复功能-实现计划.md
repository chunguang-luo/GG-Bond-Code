# 会话恢复功能实现计划

> 功能：退出时自动保存会话，支持 `nextcode --resume <session_id>` 恢复对话

## 一、功能描述

### 1.1 退出时显示会话摘要

```
Resume this session with:
  nextcode --resume 20260724_173849_8e8633

Session:        20260724_173849_8e8633
Title:          NextCode 学习计划
Duration:       21h 30m 48s
Messages:       212 (8 user, 172 tool calls)
```

### 1.2 恢复会话

```bash
nextcode --resume 20260724_173849_8e8633
```

### 1.3 设置会话标题

```bash
nextcode -t "NextCode 学习计划"
```

### 1.4 列出历史会话

```bash
nextcode --sessions
```

```
20260724_173849_8e8633  21h 30m  NextCode 学习计划
20260725_091230_a1b2c3  2h 15m   Debug login issue
```

## 二、Session ID 格式

```
20260724_173849_8e8633
|         |       |_______ 6位随机 hex (16^6=1600万种，防碰撞)
|         |_______________ HHMMSS 启动时间
|_________________________ YYYYMMDD 启动日期
```

生成代码：
```python
import secrets, time
ts = time.strftime("%Y%m%d_%H%M%S")
rand = secrets.token_hex(3)  # 6 chars
session_id = f"{ts}_{rand}"
```

## 四、改造文件清单

### 4.1 新增文件

| 文件 | 说明 |
|------|------|
| `nextcode/src/next_code/session.py` | 会话管理核心模块 |

提供函数：
- `generate_session_id()` → `str`
- `save_session(store, loop_state)` → 保存到 `.nextcode/sessions/`
- `load_session(session_id)` → `dict | None`
- `list_sessions()` → 列出所有已保存会话
- `format_exit_summary(store, loop_state)` → `str`

### 4.2 修改文件

| 文件 | 改动 |
|------|------|
| `nextcode/src/next_code/setup.py` | `setup()` 中生成 `session_id`；新增 `resume_from` 参数加载历史消息 |
| `nextcode/src/next_code/main.py` | 新增 `--resume`、`-t/--title`、`--sessions` CLI 参数；退出前 `save_session()` + print 摘要 |
| `nextcode/src/next_code/state/transition.py` | `LoopState` 新增 `user_message_count`、`tool_call_count` |
| `nextcode/src/next_code/query.py` | 每个 user 消息递增 `user_message_count`，每个 tool_call 递增 `tool_call_count` |
| `nextcode/src/next_code/commands/exit.py` | `/exit`/`/q` 附带 session 元信息 |
| `nextcode/src/next_code/ipc/bridge.py` | `SHUTDOWN` 处理时调用 `format_exit_summary()` + `save_session()` |
| `nextcode/frontend/src/app.tsx` | `/exit` 不本地 `exit()`，等后端 `SESSION_SHUTDOWN` 再退出 |

## 五、核心流程

### 5.1 启动流程（改造后）

```
nextcode [--resume <id>] [-t <title>]
  │
  ├─ main.py 解析 CLI 参数
  │   ├─ --resume → 从 .nextcode/sessions/<id>.json 加载
  │   └─ -t → 写入 store["title"]
  │
  ├─ setup.py
  │   ├─ 生成 session_id（写入 store）
  │   ├─ 如果有 --resume：恢复 messages 到 store
  │   └─ 如果无 --resume：messages = []（全新会话）
  │
  ├─ 启动 Ink 前端（跳过 welcome 如果 --resume）
  └─ REPL 循环
```

### 5.2 退出流程（改造后）

```
用户输入 /exit 或 /q
  │
  ├─ 前端 sendEvent("user.command", {command: "/exit"})
  │
  ├─ 后端 bridge._handle_command
  │   └─ handle_exit → ResultType.SHUTDOWN
  │
  ├─ bridge 处理 SHUTDOWN：
  │   ├─ save_session(store, loop_state)
  │   │   └─ 写 .nextcode/sessions/<session_id>.json
  │   ├─ summary = format_exit_summary(...)
  │   └─ sendEvent("session.shutdown", {summary})
  │
  ├─ 前端收到 SESSION_SHUTDOWN
  │   ├─ 显示摘要文本
  │   ├─ transport.close()
  │   └─ exit()
  │
  └─ main.py finally 块清理资源
```

### 5.3 恢复流程

```
nextcode --resume 20260724_173849_8e8633
  │
  ├─ 读取 .nextcode/sessions/20260724_173849_8e8633.json
  ├─ 将 messages 加载到 store["messages"]
  ├─ 恢复 cwd、model 等元信息
  ├─ 启动 Ink 前端，不显示 welcome
  └─ 用户立即可以继续之前的对话
```

## 六、前端改动细节

`app.tsx` 中 `/exit` 处理改动：

```typescript
// 旧：直接 exit()
if (text.toLowerCase() === "/exit" || text.toLowerCase() === "/quit") {
  exit();
}

// 新：发送命令给后端，等 SESSION_SHUTDOWN 再退出
// 移除本地 exit() 调用，由 SESSION_SHUTDOWN handler 负责退出
```

`app.tsx` 中 `SESSION_SHUTDOWN` handler 改动：

```typescript
case CoreToInk.SESSION_SHUTDOWN: {
  const summary = (msg.payload as { summary?: string }).summary;
  if (summary) {
    // 在终端输出退出摘要
    process.stderr.write("\n" + summary + "\n\n");
  }
  transport.close();
  exit();
  break;
}
```

## 七、计数器注入点

`query.py` 中 `QueryRunner.run()` 的循环体内：

```python
# 用户消息计数（run() 入口）
self._loop_state.user_message_count += 1

# 工具调用计数（tool_use 处理时）
self._loop_state.tool_call_count += 1
```
