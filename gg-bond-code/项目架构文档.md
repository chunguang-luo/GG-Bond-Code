## 启动链路

```
cli.py (Click entry)
  │
  ├─ 快速路径: --version → 直接打印返回
  ├─ 快速路径: --print → 非交互模式
  │
  └─ 正常路径:
      → init()        # 配置、认证、API 预连接
      → setup()       # 工作目录、会话状态
      → repl.launch() # 进入 REPL
```

## 关键设计决策

1. **Click 而非 Typer**：Typer 底层是 Click，但 Click 更灵活，对子命令和 pre-action hook 支持更好
2. **Rich 而非 Textual**：Textual 是 TUI 框架（类 Ink），但对 MVP 来说太重。Rich 足以处理流式 Markdown + 进度条 + 权限确认
3. **asyncio 全异步**：API 调用、工具执行、流式输出都需要异步
4. **Pydantic 做 Tool schema**：同时用于参数验证和生成 JSON Schema 给 API
5. **Setting 配置**：JSON 格式，`~/.ggbond/.settings.json`（全局）+ `.ggbond/.settings.json`（项目级），支持权限持久化

## 实现顺序

1. `cli.py` → `init.py` → `main.py` — 跑通启动链路
2. `query.py` → `api/` — 跑通对话循环
3. `tools/` — 实现核心工具
4. `prompts/` — System Prompt 组装
5. `permissions/` — 权限系统
6. `repl.py` + `ui/` — 交互式 REPL
7. `agents/` — 多 Agent 协调 + 任务系统
8. `context/` — Prompt Cache + 上下文压缩
9. `memory/` — Memory 系统
