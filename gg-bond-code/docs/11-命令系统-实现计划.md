# 命令系统 — 实现计划

> 基于原文档：`claude-code-docs/11-命令系统.md`

## 文档核心要点总结

### 核心概念

1. **三种执行模型统一**：`PromptCommand | LocalCommand | LocalJSXCommand` 通过联合类型聚合到 `Command` 接口
2. **六源聚合**：Bundled Skills → Builtin Plugin Skills → Skill Dir → Workflow → Plugin → Builtin Commands，扩展优先于内建
3. **懒加载设计**：`load()` 方法延迟加载实现模块，index 只含元数据，启动零成本
4. **Skill 即 Prompt 生成器**：Markdown → Frontmatter 解析 → `getPromptForCommand()` 生成 prompt
5. **条件激活 + 渐进发现**：`paths` glob 条件激活，动态目录发现（文件操作时向上遍历 `.claude/skills/`）
6. **SkillTool 桥接**：模型通过 SkillTool 调用命令，展示列表与执行集合分离
7. **缓存与失效**：memoize 缓存 + Signal 机制通知清理

### 关键设计模式

- **模式 1**：联合类型 + 懒加载的命令注册
- **模式 2**：多源聚合 + 优先级排序（合并顺序即优先级）
- **模式 3**：条件激活 + 渐进发现（运行时按需发现 Skill）

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Any, Callable, Coroutine, Protocol


@dataclass
class CommandBase:
    """共享元数据协议 — mirrors CommandBase in types/command.ts"""
    name: str
    description: str
    aliases: list[str] = field(default_factory=list)
    is_hidden: bool = False
    is_enabled: Callable[[], bool] = field(default=lambda: True)
    user_invocable: bool = True
    when_to_use: str | None = None
    loaded_from: str | None = None  # 'skills' | 'bundled' | 'mcp' | 'plugin' | None
    kind: str | None = None         # 'workflow' | None
    immediate: bool = False


@dataclass
class LocalCommand(CommandBase):
    """本地执行命令 — mirrors LocalCommand in types/command.ts

    执行后返回文本结果，不需要模型参与。
    使用 load() 实现懒加载。
    """
    type: str = field(default="local", init=False)
    supports_non_interactive: bool = False
    load: Callable[[], Coroutine[Any, Any, LocalCommandModule]] | None = None
    # 直接执行函数（如果不需要懒加载）
    handler: Callable[..., Coroutine[Any, Any, str]] | None = None


@dataclass

    生成 Prompt 发给模型处理。Skill 的底层抽象。

    type: str = field(default="prompt", init=False)
    progress_message: str = "running"
    source: str = "builtin"  # 'builtin' | 'skills' | 'mcp' | 'plugin' | 'bundled'
    arg_names: list[str] = field(default_factory=list)
    allowed_tools: list[str] = field(default_factory=list)
    model: str | None = None
    context: str = "inline"  # 'inline' | 'fork'
    agent: str | None = None
    effort: str | None = None
    paths: list[str] = field(default_factory=list)
    get_prompt: Callable[..., Coroutine[Any, Any, list[dict]]] | None = None

Command = LocalCommand | PromptCommand
```

#### Task 1.3：创建 CommandRegistry + Dispatcher

```python
# commands/registry.py
from __future__ import annotations
from functools import lru_cache
from typing import Any

from .types import Command, LocalCommand, PromptCommand


class CommandRegistry:
    """命令注册表 — mirrors COMMANDS() in commands.ts"""

    def __init__(self) -> None:
        self._commands: dict[str, Command] = {}
        self._alias_map: dict[str, str] = {}  # alias → canonical name

    def register(self, command: Command) -> None:
        self._commands[command.name] = command
        for alias in command.aliases:
            self._alias_map[alias] = command.name

    def get(self, name: str) -> Command | None:
        # 先查别名
        canonical = self._alias_map.get(name, name)
        return self._commands.get(canonical)

    def all_commands(self) -> list[Command]:
        return list(self._commands.values())

    def user_invocable_commands(self) -> list[Command]:
        return [c for c in self._commands.values() if c.user_invocable and not c.is_hidden]


# commands/dispatcher.py
from __future__ import annotations
from typing import Any

from .types import Command, LocalCommand, PromptCommand
from .registry import CommandRegistry


class CommandDispatcher:
    """命令分派器 — mirrors processSlashCommand.tsx"""

    def __init__(self, registry: CommandRegistry) -> None:
        self.registry = registry

    async def dispatch(self, raw_input: str, context: Any) -> CommandResult:
        """分派斜杠命令执行"""
        parts = raw_input.strip().lstrip("/").split(maxsplit=1)
        name = parts[0].lower()
        args = parts[1] if len(parts) > 1 else ""

        command = self.registry.get(name)
        if command is None:
            return CommandResult(type="unknown", name=name)

        if isinstance(command, LocalCommand):
            return await self._dispatch_local(command, args, context)
        elif isinstance(command, PromptCommand):
            return await self._dispatch_prompt(command, args, context)

        return CommandResult(type="error", content=f"Unknown command type: {command.type}")

    async def _dispatch_local(self, cmd: LocalCommand, args: str, context: Any) -> CommandResult:
        if cmd.load:
            mod = await cmd.load()
            result = await mod.call(args, context)
        elif cmd.handler:
            result = await cmd.handler(args, context)
        else:
            return CommandResult(type="error", content=f"No handler for {cmd.name}")
        return CommandResult(type="local", name=cmd.name, content=result)

    async def _dispatch_prompt(self, cmd: PromptCommand, args: str, context: Any) -> CommandResult:
        if cmd.get_prompt is None:
            return CommandResult(type="error", content=f"No prompt generator for {cmd.name}")
        content = await cmd.get_prompt(args, context)
        return CommandResult(type="prompt", name=cmd.name, content=content)


@dataclass
class CommandResult:
    """命令执行结果"""
    type: str  # "local" | "prompt" | "unknown" | "error"
    name: str = ""
    content: Any = None
```

```python
# skills/frontmatter.py
from __future__ import annotations
import re
from dataclasses import dataclass, field
from typing import Any


@dataclass
class SkillFrontmatter:
    """解析后的 Skill 元数据"""
    description: str = ""
    allowed_tools: list[str] = field(default_factory=list)
    model: str | None = None
    context: str = "inline"      # 'inline' | 'fork'
    agent: str | None = None
    effort: str | None = None
    when_to_use: str | None = None
    argument_hint: str | None = None
    user_invocable: bool = True
    paths: list[str] = field(default_factory=list)
    hooks: dict[str, Any] = field(default_factory=dict)


_FRONTMATTER_RE = re.compile(r"^---\s*\n(.*?)\n---\s*\n", re.DOTALL)


def parse_frontmatter(content: str) -> tuple[SkillFrontmatter, str]:
    """解析 Markdown 文件的 YAML frontmatter，返回 (元数据, 正文)"""
    match = _FRONTMATTER_RE.match(content)
    if not match:
        return SkillFrontmatter(), content

    yaml_str = match.group(1)
    body = content[match.end():]

    # 简单 YAML 解析（避免引入 pyyaml 依赖）
    fm = SkillFrontmatter()
    for line in yaml_str.splitlines():
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        if ":" not in line:
            continue
        key, _, value = line.partition(":")
        key = key.strip().lower().replace("-", "_")
        value = value.strip()

        if key == "description":
            fm.description = value
        elif key == "allowed_tools":
            fm.allowed_tools = [v.strip() for v in value.split(",")]
        elif key == "model":
            fm.model = value
        elif key == "context":
            fm.context = value
        elif key == "agent":
            fm.agent = value
        elif key == "effort":
            fm.effort = value
        elif key == "when_to_use":
            fm.when_to_use = value
        elif key == "argument_hint":
            fm.argument_hint = value
        elif key == "user_invocable":
            fm.user_invocable = value.lower() in ("true", "yes", "1")
        elif key == "paths":
            fm.paths = [v.strip() for v in value.split(",")]
        elif key == "hooks":
            fm.hooks = _parse_hooks_yaml(value)  # 简化处理

    return fm, body
```

```python
async def load_skills_from_dir(
    skill_dir: Path,
    source: str = "skills",
    loaded_from: str = "skills",
) -> list[Command]:
    """从目录加载所有 Skill"""
    if not skill_dir.is_dir():
        return []

    commands: list[Command] = []

    # 新格式：目录/SKILL.md
    for entry in sorted(skill_dir.iterdir()):
        if entry.is_dir():

        # 旧格式兼容：单文件 .md

            skill_name = entry.stem
            cmd = await _load_skill_file(entry, skill_name, source, "commands_DEPRECATED", str(entry.parent))
            if cmd:
                commands.append(cmd)

    return commands
```

#### Task 2.3：create_skill_command — Markdown → PromptCommand

```python
# skills/create_command.py
from __future__ import annotations
import re
from typing import Any

from .frontmatter import SkillFrontmatter
from ..commands.types import PromptCommand


def create_skill_command(
    skill_name: str,
    markdown_content: str,
    frontmatter: SkillFrontmatter,
    source: str,
    loaded_from: str,
    base_dir: str | None = None,
) -> PromptCommand:
    """将 Markdown Skill 转换为 PromptCommand — mirrors createSkillCommand()"""

    async def get_prompt(args: str, context: Any) -> list[dict]:
        content = markdown_content

        # 1. 参数替换：${ARG1} → 用户传入的参数
        if args and frontmatter.argument_hint:
            arg_names = [a.strip() for a in frontmatter.argument_hint.split()]
            parts = args.split(maxsplit=len(arg_names) - 1) if arg_names else [args]
            for i, arg_name in enumerate(arg_names):
                if i < len(parts):
                    content = content.replace(f"${{{arg_name}}}", parts[i])

        # 2. 目录变量替换：${GGBOND_SKILL_DIR} → 技能目录路径
        if base_dir:
            content = content.replace("${GGBOND_SKILL_DIR}", base_dir)

        # 3. 内联 Shell 命令执行：!`cmd` → 实际执行结果
        #    非 MCP 来源才执行（安全考虑）
        if loaded_from != "mcp":
            content = await _execute_inline_shell(content)

        return [{"type": "text", "text": content}]

    return PromptCommand(
        name=skill_name,
        description=frontmatter.description or f"Skill: {skill_name}",
        source=source,
        loaded_from=loaded_from,
        progress_message=f"running {skill_name}",
        arg_names=_parse_arg_names(frontmatter.argument_hint),
        allowed_tools=frontmatter.allowed_tools,
        model=frontmatter.model,
        context=frontmatter.context,
        agent=frontmatter.agent,
        effort=frontmatter.effort,
        when_to_use=frontmatter.when_to_use,
        user_invocable=frontmatter.user_invocable,
        paths=frontmatter.paths,
        get_prompt=get_prompt,
    )


async def _execute_inline_shell(content: str) -> str:
    """执行 Markdown 中的内联 Shell 命令：!`cmd` → 结果"""
    import asyncio

    def replace_match(m: re.Match) -> str:
        cmd = m.group(1)
        try:
            # 同步执行（简化版，实际应考虑超时和安全）
            proc = asyncio.create_subprocess_shell(
                cmd, stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.PIPE
            )
            # 这里简化处理，实际需要 await
            return m.group(0)  # 暂时不执行，返回原文
        except Exception:
            return m.group(0)

    return re.sub(r"!`([^`]+)`", replace_match, content)


def _parse_arg_names(hint: str | None) -> list[str]:
    if not hint:
        return []
    return [a.strip().lstrip("<").rstrip(">") for a in hint.split() if a.strip()]
```

```python
"""SkillTool — allows the model to invoke slash commands via tool calls."""
from __future__ import annotations
import json
from typing import Any

from .base import Tool, ToolResult


class SkillTool(Tool):
    name = "Skill"
    description = (
        "Execute a skill by name. Skills are slash commands that can be "
        "invoked by the model during conversation."
    )

    def get_schema(self) -> dict[str, Any]:
        return {
            "type": "object",
            "properties": {
                "skill": {
                    "type": "string",
                    "description": "The skill name to invoke",
                },
                "args": {
                    "type": "string",
                    "description": "Optional arguments for the skill",
                },
            },
            "required": ["skill"],
        }

    async def execute(self, params: dict[str, Any]) -> ToolResult:
        from ..commands.registry import get_global_registry
        from ..commands.types import PromptCommand

        registry = get_global_registry()
        skill_name = params["skill"]
        args = params.get("args", "")

        command = registry.get(skill_name)
        if command is None:
            return ToolResult(output=f"Unknown skill: {skill_name}", error=True)

        if not isinstance(command, PromptCommand):
            return ToolResult(output=f"Not a prompt skill: {skill_name}", error=True)

        if command.get_prompt is None:
            return ToolResult(output=f"Skill has no prompt generator: {skill_name}", error=True)

        content = await command.get_prompt(args, self._context)
        # 将 prompt 内容作为用户消息返回
        text = "\n".join(block.get("text", "") for block in content if block.get("type") == "text")
        return ToolResult(output=text)
```

```python
"""Command system caching — mirrors memoize + clearCommandMemoizationCaches."""
from __future__ import annotations
from functools import wraps
from typing import Any, Callable


def memoize_async(fn: Callable) -> Callable:
    """Async memoize — caches result until explicitly cleared."""
    cache_key = f"__memo_{fn.__name__}"

    @wraps(fn)
    async def wrapper(*args, **kwargs):
        from ..state.store import Store
        store = Store()
        cached = store.get(cache_key)
        if cached is not None:
            return cached
        result = await fn(*args, **kwargs)
        store.set(cache_key, result)
        return result

    wrapper.cache_clear = lambda: Store().set(cache_key, None) if Store().has(cache_key) else None
    return wrapper


def clear_command_caches() -> None:
    """Clear all command-related caches — mirrors clearCommandMemoizationCaches."""
    from ..state.store import Store
    store = Store()
    for key in list(store.get("__state__", {}).keys()):
        if key.startswith("__memo_"):
            store.delete(key)
```

```python
# skills/conditional.py
"""Conditional skill activation — mirrors activateConditionalSkillsForPaths."""
from __future__ import annotations
from fnmatch import fnmatch
from pathlib import Path

from ..commands.types import PromptCommand


class ConditionalSkillManager:
    """管理条件 Skill 的激活状态"""

    def __init__(self) -> None:
        self._pending: dict[str, PromptCommand] = {}   # 待激活
        self._activated: dict[str, PromptCommand] = {}  # 已激活

    def register_conditional(self, command: PromptCommand) -> None:
        """注册条件 Skill（paths 非空但尚未匹配）"""
        if command.paths:
            self._pending[command.name] = command

    def activate_for_paths(self, file_paths: list[str], cwd: str) -> list[str]:
        """检查文件路径是否激活条件 Skill"""
        activated_names: list[str] = []
        for name, cmd in list(self._pending.items()):
            for file_path in file_paths:
                rel = str(Path(file_path).relative_to(cwd)) if file_path.startswith(cwd) else file_path
                for pattern in cmd.paths:
                    if fnmatch(rel, pattern):
                        self._activated[name] = cmd
                        del self._pending[name]
                        activated_names.append(name)
                        break
        return activated_names

    def get_activated(self) -> list[PromptCommand]:
        return list(self._activated.values())
```

```python
async def discover_skill_dirs_for_paths(
    file_paths: list[str],
    cwd: str,
) -> list[Path]:
    """渐进式 Skill 目录发现 — mirrors discoverSkillDirsForPaths

    从文件所在目录向上遍历到 cwd，查找 .ggbond/skills/ 目录。
    """
    discovered: list[Path] = []
    seen: set[str] = set()
    resolved_cwd = str(Path(cwd).resolve())

    for file_path in file_paths:
        current = str(Path(file_path).resolve().parent)
        while current.startswith(resolved_cwd + "/"):
            skill_dir = Path(current) / ".ggbond" / "skills"
            key = str(skill_dir)
            if key not in seen:
                seen.add(key)
                if skill_dir.is_dir():
                    discovered.append(skill_dir)
            current = str(Path(current).parent)

    return discovered
```

## 可迁移的设计模式

### 模式 1：联合类型 + 懒加载的命令注册

- **类别**：结构模式
- **描述**：用联合类型定义多种执行模型，对重量级实现使用 `load()` 懒加载
- **适用场景**：任何有大量命令/插件/扩展的系统
- **Python 实现**：

```python
Command = LocalCommand | PromptCommand

@dataclass
class LocalCommand(CommandBase):
    type: str = "local"
    load: Callable[[], Awaitable[ModuleType]] | None = None  # 懒加载
    handler: Callable | None = None  # 直接执行（轻量命令）
```

### 模式 2：多源聚合 + 优先级排序

- **类别**：结构模式
- **描述**：将来自不同来源的同构对象合并到一个列表中，通过合并顺序控制优先级
- **适用场景**：多层配置合并、多插件系统
- **Python 实现**：

```python
async def load_all_commands(cwd: str) -> list[Command]:
    skills, builtin = await asyncio.gather(load_skills(cwd), load_builtin())
    return [...skills, ...builtin]  # 扩展优先
```

### 模式 3：条件激活 + 渐进发现

- **类别**：行为模式
- **描述**：不在启动时加载所有扩展，运行中根据用户行为逐步发现
- **适用场景**：大型项目中的子模块配置发现、IDE 插件按需激活
- **Python 实现**：

```python
def activate_for_paths(self, file_paths: list[str], cwd: str) -> list[str]:
    for name, cmd in self._pending.items():
        for path in file_paths:
            if matches_glob(path, cmd.paths):

```

## 为什么要做（业务动机）

### 阶段 1：为什么要重构 Command 类型体系？

**问题**：当前 REPL 和 IPC Bridge 各自用 if/elif 链硬编码命令处理，同一个命令（如 `/clear`）需要在两个地方维护。新增命令需要改 3+ 个文件，容易遗漏或不一致。

**价值**：
- **单一来源**：命令定义只需写一次，REPL 和 IPC Bridge 共享同一份注册表
- **可扩展**：第三方可以通过注册表添加命令，不需要改核心代码
- **可发现**：`/help` 从注册表自动生成，不需要手动维护帮助文本
- **可测试**：每个命令是独立模块，可以单独写单元测试

### 阶段 2：为什么要做 Skill 加载系统？

**问题**：用户无法自定义命令。例如用户想要一个 `/review` 命令自动做 code review，当前只能手动写 prompt。

**价值**：
- **用户自定义**：用户在 `.ggbond/skills/` 放一个 Markdown 文件就自动成为斜杠命令
- **团队共享**：项目级 `.ggbond/skills/` 可以提交到 git，团队共享工作流
- **Frontmatter 配置**：YAML 头部可以限制工具集（`allowed_tools`）、指定模型（`model`）等
- **懒加载**：启动时只扫描目录，不加载实现，不拖慢启动速度

### 阶段 3：为什么要做 SkillTool 桥接？

**问题**：当前模型只能"被动"响应，不能主动调用命令。例如模型在做代码审查时无法自动调用 `/compact` 来压缩上下文。

**价值**：
- **模型主动调用**：模型通过 SkillTool 触发命令，实现更智能的工作流编排
- **缓存**：命令结果缓存避免重复执行，`clear_command_caches()` 在状态变化时失效

### 阶段 4：为什么要做条件激活 + 动态发现？

**问题**：所有 Skill 启动时全部加载，但大部分在当前工作目录下用不到。例如前端项目的 Skill 在后端项目中没有意义。

**价值**：
- **按需加载**：只有当操作匹配文件时才激活相关 Skill（如 `paths: ["*.tsx"]` 的 Skill 只在前端文件操作时激活）
- **渐进发现**：文件操作时向上遍历目录查找 `.ggbond/skills/`，大型 monorepo 不会加载无关 Skill
- **性能优化**：减少无关 Skill 对上下文窗口的占用
