# 工具系统设计 — 实现计划

> 基于原文档：`claude-code-docs/09-工具系统设计.md`

## 文档核心要点总结

### 核心概念

1. **Tool 接口即微服务**：工具不仅仅是执行逻辑，它是自带输入验证、权限控制、UI 渲染、结果序列化的完整"微服务"
2. **Fail-closed 安全默认值**：Claude Code 通过 `buildTool()` 的对象展开合并提供安全默认；Python 中直接在 ABC 上提供 fail-closed 默认方法即可达到同样效果
3. **分层条件注册**：编译期 DCE → 模块加载时 env → 运行时 `isEnabled()` → 权限 deny rules，四层过滤漏斗
4. **并发安全分区**：`isConcurrencySafe` 将批量 tool_use 分区为可并发组和必须串行组，默认 `false` 确保安全
5. **ToolSearch 延迟加载**：MCP 工具以名称列表告知模型，按需通过 ToolSearchTool 发现并加载完整定义
6. **lazySchema**：Zod schema 延迟构造，避免模块加载时的性能开销

### 关键设计模式

| 模式 | 核心思想 | 适用场景 |
|------|---------|---------|
| ABC fail-closed 默认值 | 基类提供安全默认，子类按需覆盖 | 插件/中间件系统 |
| 分层条件注册 | 编译期→加载期→运行时→权限四层过滤 | 多版本构建 |
| 并发安全分区 | `isConcurrencySafe` 标记 + reduce 分组 | 异构批量执行 |
| 延迟加载 | 只暴露工具名，按需搜索加载完整定义 | 大规模工具集 |
| 目录组织 | `ToolName/ToolName.ts + prompt.ts + UI.tsx` | 工具模块化 |

### Phase 1: Tool ABC 安全默认值扩展 (P0)

**目标**：在 Tool ABC 上添加 fail-closed 安全默认方法，子类按需覆盖即可

**设计决策**：不引入 `build_tool()` Builder

Claude Code 用 `buildTool()` 解决的是 TypeScript 特有问题——30+ 方法的接口实现负担、`BuiltTool<D>` 类型层 spread 语义模拟、`satisfies` 结构校验。Python 中这些都不存在：ABC 的虚方法直接给默认实现即可，不需要额外的 Builder 层。核心要移植的是 **fail-closed 安全默认值** 这个思想，不是 `buildTool()` 这个机制。

```python
class Tool(ABC):
    # ... 现有代码 ...

    # ── 安全域方法（fail-closed 默认值）──
    # 默认值与 Claude Code TOOL_DEFAULTS 一致：
    # isReadOnly → False, isConcurrencySafe → False, isDestructive → False
    # 忘记声明时采用最保守假设 —— 这就是 fail-closed

    def is_enabled(self) -> bool:
        """工具是否在当前环境下可用。默认 True。"""
        return True

    def is_read_only(self, params: dict[str, Any]) -> bool:
        """是否为只读操作。默认 False（fail-closed：假设写入）。"""
        return False

    def is_destructive(self, params: dict[str, Any]) -> bool:
        """是否为不可逆操作。默认 False。"""
        return False

    async def validate_input(self, params: dict[str, Any]) -> tuple[bool, str]:
        """输入预校验（在权限检查之前）。返回 (is_valid, error_message)。"""
        return (True, "")

    async def check_permissions(self, params: dict[str, Any]) -> tuple[str, dict[str, Any]]:
        """权限检查。返回 (behavior, updated_input)。
        behavior: 'allow' | 'deny' | 'ask'
        默认 allow — 交给通用权限系统处理。
        """
        return ("allow", params)

    # ── 辅助属性 ──
    search_hint: str = ""
    aliases: list[str] = []

    def user_facing_name(self, params: dict[str, Any] | None = None) -> str:
        """用户可见的工具名称。默认返回 self.name。"""
        return self.name
```

**任务 2.2：StreamingToolExecutor 集成 check_permissions**

在权限检查阶段，先查询工具自身的 `check_permissions()`：

```python
async def _check_permission(self, execution: ToolExecution) -> str:
    """Combined permission check: tool-level + global rules."""
    tool = self.registry.get(execution.tool_name)
    if tool:
        behavior, updated_input = await tool.check_permissions(execution.input)
        if behavior == "deny":
            return PD_DENY
        elif behavior == "allow":
            execution.input = updated_input  # 工具可能修改输入
            return PD_ALLOW

    # Fall back to global PermissionManager
    if self._context is not None:
        decision = self._context.permissions.check(execution.tool_name, execution.input)
        if decision.value == "allow":
            return PD_ALLOW
        elif decision.value == "deny":
            return PD_DENY

    return PD_ALLOW  # 无权限系统时默认允许
```

**任务 2.3：GlobTool 添加 validate_input**

```python
async def validate_input(self, params: dict[str, Any]) -> tuple[bool, str]:
    """验证路径安全（UNC 路径检查、目录存在性）。"""
    path = params.get("path")
    if path:
        abs_path = Path(path).resolve()
        # UNC 路径安全检查（防止 NTLM 凭据泄露）
        if str(abs_path).startswith("\\\\") or str(abs_path).startswith("//"):
            return (True, "")  # 文档中也是返回 true
        if not abs_path.exists():
            return (False, f"Directory not found: {abs_path}")
    return (True, "")
```

```python
async def check_permissions(self, params: dict[str, Any]) -> tuple[str, dict[str, Any]]:
```

```python
# gg-bond-code/src/gg_bond_code/tools/registry.py

def get_all_base_tools() -> list[Tool]:
    """单一来源工具清单 — mirrors getAllBaseTools() in tools.ts."""
    tools = [
        BashTool(),
        FileReadTool(),
        FileEditTool(),
        FileWriteTool(),
        GlobTool(),
        GrepTool(),
    ]
    # 条件注册：运行时 isEnabled() 检查
    return [t for t in tools if t.is_enabled()]


def get_tools(
    permission_context: PermissionManager,
    simple_mode: bool = False,
) -> list[Tool]:
    """从注册表到模型实际可用的工具，经过多层过滤。

    Mirrors getTools() in tools.ts:271-327.
    过滤漏斗：simple_mode → deny rules → isEnabled()
    """
    if simple_mode:
        base = [BashTool(), FileReadTool(), FileEditTool()]
        return _filter_by_deny_rules(base, permission_context)

    all_tools = get_all_base_tools()
    return _filter_by_deny_rules(all_tools, permission_context)


def assemble_tool_pool(
    permission_context: PermissionManager,
    extra_tools: list[Tool] | None = None,
) -> list[Tool]:
    """合并内置工具与外部工具 — mirrors assembleToolPool().

    按名称排序（prompt cache 稳定性），built-in 优先。
    """
    built_in = get_tools(permission_context)
    external = extra_tools or []

    # 过滤外部工具
    allowed_external = _filter_by_deny_rules(external, permission_context)

    # 排序：built-in 和 external 分别排序后拼接
    by_name = lambda t: t.name
    return list(dict.fromkeys(
        sorted(built_in, key=by_name) + sorted(allowed_external, key=by_name)
    ))
```

```python
class ToolRegistry:
    def __init__(self, tools: list[Tool] | None = None) -> None:
        self._tools: dict[str, Tool] = {}
        self._schema_cache: dict[tuple[str, str], dict[str, Any]] = {}
        if tools:
            for tool in tools:
                self.register(tool)

    @classmethod
    def from_permission_context(cls, permission_context: PermissionManager) -> "ToolRegistry":
        """根据权限上下文创建注册表 — 使用 assemble_tool_pool。"""
        tools = assemble_tool_pool(permission_context)
        return cls(tools=tools)
```

```python
def is_deferred_tool(tool: Tool) -> bool:
    """判断工具是否应该延迟加载 — mirrors isDeferredTool()."""
    # 显式 opt-out
    if getattr(tool, "always_load", False):
        return False
    # MCP 工具：总是延迟
    if getattr(tool, "is_mcp", False):
        return True
    # ToolSearch 自身不延迟
    if tool.name == "ToolSearch":
        return False
    # 其他：通过 should_defer 标记
    return getattr(tool, "should_defer", False)
```

```python
    async def _search_with_keywords(self, query, deferred_tools, max_results):
        """评分搜索 — mirrors searchToolsWithKeywords."""
        scores = []
        query_lower = query.lower()
        for tool in deferred_tools:
            score = 0
            # name 部分精确匹配: 10 分
            if query_lower in tool.name.lower():
                score += 10
            # searchHint 匹配: 4 分

        return [t for _, t in scores[:max_results]]
```

## 风险评估

### 架构风险

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| Tool ABC 添加新方法可能影响自定义工具子类 | 中 | 所有新方法都有默认实现，子类无需修改即可工作 |
| validate_input/check_permissions 引入后改变执行流程 | 中 | 确保默认实现不改变现有行为（validate_input 默认返回 True，check_permissions 默认返回 allow） |
| ToolRegistry 重构可能影响 QueryRunner | 中 | 保持 Registry 公共 API 不变（register/get/all_tools/to_api_format），内部实现可改 |

### 性能风险

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| validate_input 增加每次工具调用的开销 | 低 | 默认实现为空操作，仅在实际覆盖时有开销 |
| 条件注册每次调用 get_all_base_tools() 都实例化工具 | 低 | 可加缓存，或改为类级别检查 |

### 向后兼容风险

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| PermissionManager 移除 read_only_tools 硬编码 | 低 | 通过 is_read_only() 动态查询，行为一致 |

## 可迁移的设计模式

### 模式 1：ABC Fail-closed 安全默认值

```python
# 行为模式：基类提供 fail-closed 默认值，子类按需覆盖
#
# Claude Code 用 buildTool() + spread merge 实现同一目标，
# 但那是 TypeScript 特有的解法（解决接口方法过多 + 类型推断）。
# Python 中直接在 ABC 上给默认实现即可达到同样效果。

class Tool(ABC):
    def is_concurrency_safe(self, params) -> bool:
        return False  # fail-closed: 默认假设不安全

    def is_read_only(self, params) -> bool:
        return False  # fail-closed: 默认假设写入

    def is_destructive(self, params) -> bool:
        return False

    async def check_permissions(self, params) -> tuple[str, dict]:
        return ("allow", params)  # 交给通用权限系统

# 子类只需覆盖自己关心的方法
class GlobTool(Tool):
    def is_read_only(self, params) -> bool:
        return True

    def is_concurrency_safe(self, params) -> bool:
        return True
```

**适用场景**：任何插件/中间件系统，特别是涉及安全敏感操作时。Python 中 ABC + 默认实现比 Builder 模式更自然。

### 模式 2：分层条件注册（Python 版本）

```python
# 行为模式：编译期 DCE → 模块加载时 env → 运行时 isEnabled() → deny rules

# Python 无编译期 DCE，用 lazy import 替代
def get_all_base_tools():
    tools = [BashTool(), FileReadTool(), ...]
    # 运行时环境变量
    if os.getenv("ENABLE_AGENT") == "true":
        from .agent import AgentTool  # lazy import
        tools.append(AgentTool())
    # 运行时 isEnabled()
    return [t for t in tools if t.is_enabled()]
```
