# 需求设计文档（简化主流程版）

## 目标

用 Python 重新实现 Claude Code CLI 的核心主流程，保留架构精髓，去掉企业级复杂度。

| API 预连接 | |

## 核心流程

```
用户输入 cli 命令
  → 快速路径检查（--version 等直接返回）
  → init()：配置加载、环境变量、认证
  → setup()：工作目录、会话初始化
  → REPL 循环：
      用户输入 → 组装消息+System Prompt → 调用 Anthropic API（流式）
      → 模型返回 tool_use → 执行工具 → 结果回传 → 模型继续/结束
```

## 技术栈选型（Python）

| 层级 | 原版 | Python 选型 | 理由 |
|------|------|------------|------|
| 运行时 | Bun | Python 3.12+ | 生态成熟，type hints 完善 |
| CLI 框架 | Commander.js | Click | 成熟、简洁、支持子命令 |
| 终端 UI | Ink (React) | Rich | 流式输出、Markdown 渲染、进度条 |
| 运行时验证 | Zod | Pydantic | Python 事实标准的 schema 验证 |
| API 客户端 | 自研 | anthropic SDK | 官方 SDK |
| 异步 | - | asyncio | 流式 API + 并行工具执行 |
| 配置 | JSON | TOML | Python 生态更自然 |
