# GG Bond Code 使用文档

## 安装

```bash
cd gg-bond-code
pip install -e .
```

## 快速开始

### 配置 API Key

方式一：环境变量
```bash
# DeepSeek 模型
export GGBOND_API_KEY=your-deepseek-api-key

# Claude 模型
export ANTHROPIC_API_KEY=your-anthropic-api-key
```

方式二：交互式配置
```bash
ggbond auth
```

方式三：配置文件 `.ggbond/.settings.json`
```json
{
  "api_key": "your-api-key",
  "model": "deepseek-reasoner",
  "context": {
    "max_tokens": 65536
  }
}
```

配置文件位置：
- 全局配置：`~/.ggbond/.settings.json`
- 项目配置：`.ggbond/.settings.json`

## 命令行选项

```bash
# 查看版本
ggbond --version
ggbond -v

# 非交互模式（从 stdin 读取）
echo "解释什么是 Python 装饰器" | ggbond --print

# 指定模型
ggbond --model deepseek-reasoner
ggbond --model claude-sonnet-4-20250514

# 指定工作目录
ggbond --cwd /path/to/project

# 查看配置
ggbond config
```

## 交互式 REPL

启动交互模式：
```bash
ggbond
```

### 内置命令

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助信息 |
| `/clear` | 清空对话历史 |
| `/compact` | 压缩对话历史（保留最近 4 条） |
| `/model` | 显示当前使用的模型 |
| `/exit` `/quit` `/q` | 退出 REPL |

### 使用示例

```
ggbond> 读取当前目录下的 README.md 文件

ggbond> 在 src 目录下查找所有 Python 文件

ggbond> 运行 pytest 测试

ggbond> /clear
[对话已清空]

ggbond> /exit
Goodbye!
```

## 多模型支持

GG Bond Code 支持多种模型，自动选择对应的 API 后端：

| 模型前缀 | 后端 | Base URL | API Key 来源 |
|----------|------|----------|-------------|
| `deepseek-*` | OpenAI 兼容 | `https://api.deepseek.com` | `GGBOND_API_KEY` → settings |
| `claude-*` | Anthropic 原生 | `https://api.anthropic.com` | `ANTHROPIC_API_KEY` → settings |
| 其他 | OpenAI 兼容 | `https://api.deepseek.com` | `GGBOND_API_KEY` → settings |

### 模型输出 Token 限制

| 后端 | 最大输出 Token |
|------|---------------|
| Anthropic | 8192 |
| OpenAI 兼容 | 65536 |

settings 中配置的 `max_tokens` 会自动按模型族限制，不会超出上限。

## 配置系统

配置优先级（从低到高）：
1. 默认值
2. 全局配置文件 `~/.ggbond/.settings.json`
3. 项目配置文件 `.ggbond/.settings.json`
4. 环境变量

### 配置示例

```json
{
  "api_key": "sk-your-api-key",
  "model": "deepseek-reasoner",
  "context": {
    "max_tokens": 65536
  },
  "permissions": {
    "allow": [],
    "deny": []
  }
}
```

### 环境变量

| 变量 | 说明 |
|------|------|
| `GGBOND_API_KEY` | DeepSeek 等 OpenAI 兼容模型的 API Key |
| `ANTHROPIC_API_KEY` | Claude 模型的 API Key |
| `ANTHROPIC_BASE_URL` | Anthropic API 地址（可选） |
| `GGBOND_MODEL` | 覆盖默认模型 |

## 故障排除

### API Key 未配置
```
Error: No API key found. Set GGBOND_API_KEY or run 'ggbond auth'.
```
解决：运行 `ggbond auth` 或设置环境变量 `GGBOND_API_KEY` / `ANTHROPIC_API_KEY`。

### 模块未找到
```
ModuleNotFoundError: No module named 'gg_bond_code'
```
解决：在项目目录运行 `pip install -e .`

### Anthropic 报 invalid argument
检查 `max_tokens` 配置，Claude 模型最大输出 8192，超出会自动限制。
