# 对话循环实现详细文档

## 目标

实现 `query.py` → `api/` 对话循环，完成以下核心流程：

```
用户输入 → 组装消息 + System Prompt → 调用 Anthropic API（流式）
→ 模型返回 tool_use → 执行工具 → 结果回传 → 模型继续/结束
```

### 现有问题

#### 1. `query.py` 问题

```python
# 问题：流式处理后又调用了一次非流式 API（重复请求）
async for event in stream_message(...):
    # 处理流式事件...

# 然后又调用了一次完整请求（浪费）
full_message = await client.messages.create(...)
```

**解决方案**：使用 `stream.get_final_message()` 获取完整消息，避免重复请求。

#### 2. `api/client.py` 问题

- 缺少错误重试机制
- 缺少 API 超时配置
- 缺少流式响应的完整处理

#### 3. 权限确认缺失

当 `PermissionDecision.ASK` 时，应该弹出交互式确认，但目前直接执行。

```python
# api/stream.py - 流式响应处理

@dataclass
class StreamEvent:
    type: str  # "text_start" | "text_delta" | "text_end" | "tool_start" | "tool_input_delta" | "tool_end" | "message_end"
    # 根据类型携带不同字段
    text: str = ""
    tool_id: str = ""
    tool_name: str = ""
    tool_input: str = ""  # JSON 字符串，需要累积
    message: Message | None = None  # message_end 时携带完整消息

class StreamAccumulator:
    """累积流式事件，构建完整消息"""
    
    def __init__(self):
        self.text_blocks: list[dict] = []
        self.tool_blocks: list[dict] = []
        self._current_text: str = ""
        self._current_tool_id: str = ""
        self._current_tool_name: str = ""
        self._current_tool_input: str = ""
    
    def process_event(self, event: RawMessageStreamEvent) -> StreamEvent:
        """处理原始事件，返回结构化事件"""
    
    def get_message(self) -> dict:
        """构建最终的 assistant message"""
```

### Phase 2: 重构 `query.py`

**目标**：修复重复请求问题，完善对话循环

```python
# query.py 重构方案

class QueryRunner:
    async def run(self, user_message: str) -> AsyncIterator[QueryEvent]:
        """运行对话循环"""
        messages = self._prepare_messages(user_message)
        
        for turn in range(self.max_turns):
            # 1. 流式调用 API
            accumulator = StreamAccumulator()
            async for event in stream_message(...):
                stream_event = accumulator.process_event(event)
                yield self._convert_event(stream_event)
            
            # 2. 获取完整消息（从 accumulator，不再重复请求）
            assistant_message = accumulator.get_message()
            messages.append({"role": "assistant", "content": assistant_message["content"]})
            
            # 3. 检查是否有工具调用
            tool_uses = [b for b in assistant_message["content"] if b["type"] == "tool_use"]
            if not tool_uses:
                break  # 没有工具调用，对话结束
            
            # 4. 执行工具
            tool_results = []
            for tool_use in tool_uses:
                result = await self._execute_tool_with_permission(tool_use)
                yield QueryEvent(type="tool_result", ...)
                tool_results.append(result)
            
            # 5. 添加工具结果到消息
            messages.append({"role": "user", "content": tool_results})
        
        # 6. 持久化消息
        self._persist_messages(messages)
```

```python
# tools/base.py 增强

class Tool(ABC):
    async def execute_safe(self, params: dict) -> ToolResult:
        """安全执行，捕获所有异常"""
        try:
            return await asyncio.wait_for(
                self.execute(params),
                timeout=self.get_timeout()
            )
        except asyncio.TimeoutError:
            return ToolResult(output="Tool execution timed out", error=True)
        except Exception as e:
            return ToolResult(output=f"Tool error: {e}", error=True)
    
    def get_timeout(self) -> float:
        """默认超时时间（秒）"""
        return 120.0
```
